# 改修案(あとでやること)

## UIの見た目を洗練させる(開発者の希望 2026-11-17)

**ver 0.4.0 で実施**:3案を比べて案A(淡い色の面+左端の線)に決定。線を減らす・書体を SharePoint に合わせる・灰色の箱を軽くする、は済み。行の高さ「ふつう/コンパクト」を追加。
残り:文字の大きさ・余白の段階を細かくそろえる(4.・3.の一部)
- 時期:機能が一通りできてから(フェーズ4「仕上げ」のころ)。開発者は「一通り完成してからでもいい」
- 進め方:方向の違う案を2〜3つプレビューで並べて、開発者に選んでもらう

### 気になっている点(初期版のプレビューを見て)
1. **アイコンが絵文字** → **済み(2026-11-17)**:`src/components/Icon.tsx` に線画SVGで作成。ボタンの矢印・バッジの ⓘ もそろえた。
   当初のメモ:OS によって絵柄・色がばらばらで、いちばん「素人っぽさ」が出ている
   → 線の太さをそろえた単色の SVG アイコン(自作)に置き換える。外部読み込みなし
2. **線と色が多い**:全マスの縦横の罫線、帯の太い枠線、左の色帯、区分名+行き先+時刻で、情報が多すぎてうるさい
   → 罫線は横線中心に減らす、帯の枠線をなくして淡い面だけにする、色の数をしぼる
3. **書体**:いまは 'Segoe UI', 'Yu Gothic UI', Meiryo を指定
   - WEBパーツでは SharePoint の書体をそのまま受け継ぐ(font-family: inherit)と、ポータルになじむ
   - 日本語のWebフォントを同梱すると数MBになるため使わない(外部CDNも使わない方針)
   - 太字(600)の使いすぎを減らし、文字の大きさの段階を3つ程度にそろえる
4. **余白の段階がばらばら**:4px / 8px / 12px / 16px など決まった段階にそろえる
5. **絞り込み欄の灰色の箱が重い**:表との境目をもっと軽く
