# SharePoint リストの準備と、WEBパーツの設定(開発者向け)

## 1. 行動予定リストを作る(社内ポータル。WorkerNameList と同じサイト)
- リストは最初に `ScheduleEntries` という名前で作り、あとから表示名を「行動予定」に変える
  - WEBパーツはリストを **URL(`Lists/ScheduleEntries`)で探す** ので、表示名を変えても動く
- 列は**最初に英語の名前(内部名)で作り**、あとから表示名を日本語に変える(内部名はあとから変えられないため)

| 内部名(最初にこの名前で作る) | 表示名(あとで変更) | 種類 | 必須 | 補足 |
|---|---|---|---|---|
| Title | 行き先・現場名 | 1行テキスト(既定の列) | ○ | 表示名を変えるだけ |
| Worker | 担当者 | 参照(WorkerNameList の「タイトル」) | ○ | |
| EntryType | 登録種別 | 選択肢:期間/単発 | ○ | |
| Category | 区分 | 選択肢:現場/在社/外出/出張/研修/休暇/その他 | ○ | 選択肢はあとから追加・変更してよい(WEBパーツの作り直しは不要)。ver 0.7.0 で「休み」→「休暇」(下の手順) |
| StartDate | 開始日 | 日付と時刻 →「日付のみ」 | ○ | |
| EndDate | 終了日 | 日付と時刻 →「日付のみ」 | ○ | |
| StartTime | 開始時刻 | 1行テキスト | | |
| EndTime | 終了・戻り時刻 | 1行テキスト | | |
| Note | メモ | 複数行テキスト | | 書式なし(プレーンテキスト) |

- **区分「休み」を「休暇」に変える手順**(ver 0.7.0。総務の呼び方に合わせる)
  1. 行動予定リスト →「リストの設定」→ 列「区分」を開く
  2. 選択肢の「休み」を「休暇」に書き換えて「OK」
  - 前に登録した予定は、リストの中では「休み」のまま残りますが、WEBパーツは「休暇」として表示・集計するので**直さなくてかまいません**
    (その予定を画面から編集して保存すると「休暇」に変わります)
  - 選択肢を変える前に ver 0.7.0 を入れても、保存はできます(選択肢が「休み」のうちは「休み」で書き込みます)
- **インデックス**(リストの設定 →「インデックス付きの列」):Worker・StartDate・EndDate
- **権限**
  - リストの設定 → 詳細設定:「読み取り:すべてのアイテム」「作成と編集:ユーザーが作成したアイテムのみ」
  - 一般社員:このリストに「投稿」
  - SharePoint グループ「行動予定表管理者」を作り、このリストに「編集」

## 2. 会社休日リストを作る(社内ポータル。新しく作ることに決定:2026-11-18)
既存の休日リストは別サイトにあるため使わず、社内ポータルに新しく作る。
- リストは最初に `CompanyHolidays` という名前で作り、あとから表示名を「会社休日」に変える
  - WEBパーツはリストを **URL(`Lists/CompanyHolidays`)で探す** ので、表示名を変えても動く
- 列は**最初に英語の名前(内部名)で作り**、あとから表示名を日本語に変える

| 内部名(最初にこの名前で作る) | 表示名(あとで変更) | 種類 | 必須 | 補足 |
|---|---|---|---|---|
| Title | 名称 | 1行テキスト(既定の列) | **いいえ** | 表示名を変えるだけ。**必須を外す**(下の「Title の必須の外し方」)。書きたいときだけ書く(例:元日) |
| HolidayDate | 日付 | 日付と時刻 →「日付のみ」 | ○ | 1日1件。連休は日ごとに登録 |
| DayType | 種別 | 選択肢:祝日/休業日/一斉有給/出勤日 | ○ | 「出勤日」の文字だけはこのとおりに |

- **種別の決まり**:「**出勤日**」だけが平日あつかい。**それ以外の選択肢はすべて休日あつかい**
  - 選択肢はあとから足してよい(例:創立記念日)。WEBパーツの作り直しは不要
- **日付の見出しに出る文字**:名称が書いてあれば名称、空欄なら種別の文字(例「休業日」)。「出勤日」は何も出さない
- **登録するもの**:土日は自動で休日扱いなので登録しない
  - 祝日 →「祝日」(名称に「元日」などを書いてもよい)
  - 夏季・年末年始などの会社の休み →「休業日」
  - 全社一斉の有給休暇の日 →「一斉有給」
  - 土日だけど会社として出勤の日(出勤土曜など)→「出勤日」
- **Title の必須の外し方**:リストの設定 → 列の「タイトル」(表示名を変えたあとは「名称」)をクリック →
  「この列への情報の入力を必須にする」を「いいえ」→ OK
- **権限**:全員「読み取り」。編集は開発者と管理者だけ
- WEBパーツの設定の「会社休日リストのあるサイトの URL」は**空欄のまま**(同じサイトのため)

## 3. 列の内部名を確かめる
次の URL をブラウザで開く(`<テナント>`・`<サイト>`・リスト名を差し替える)。結果を Claude Code に共有する。
```
https://<テナント>.sharepoint.com/sites/<サイト>/_api/web/lists/getbytitle('リスト名')/fields?$filter=Hidden eq false&$select=Title,InternalName,TypeAsString
```
**かんたんな方法**:リストの設定 → 列の名前をクリック → アドレスバーの URL の最後にある `Field=〇〇` が内部名(`%5F` は `_` のこと)。

対象:WorkerNameList・休暇情報共有リスト・休日出勤情報共有リスト・作業員の行き先リスト(すべて確認済み:2026-11-18)

内部名は `src/services/spConfig.ts` の `SP_FIELDS` 1か所で設定している(【要確認】の印があるのが仮の値)。

## 4. WEBパーツの設定(ページの編集 → WEBパーツの鉛筆マーク)
| 項目 | 初期値 | 説明 |
|---|---|---|
| タイトル | 行動予定表 | 予定表の上に小さく出す。空欄にすると出さない |
| ヘルプの「困ったとき」の連絡先 | (空欄) | 使い方の画面の最後に出す(例:システム担当 ◯◯ 内線 123)。空欄なら出さない |
| 部署の並び順 | (空欄=No. 順) | 上から並べたい順に1行に1部署。書かなかった部署はうしろに No. 順 |
| 予定表に出さない部署 | 退職者 | 「、」か改行で区切って複数 |
| 「自分を一番上に表示」を最初からオン | オン | |
| 休暇と単発予定が重なったら休暇を優先 | オン | 総務の休暇を優先で決定(オフにすると単発予定を優先) |
| 行動予定リスト | Lists/ScheduleEntries | リスト名、または `Lists/〜` の URL |
| 対象者リスト | WorkerNameList | |
| 休暇情報共有リスト | 休暇情報共有リスト | 確認済み(この名前のまま) |
| 休日出勤情報共有リスト | 休日出勤情報共有リスト | 確認済み(この名前のまま) |
| 会社休日リストのあるサイトの URL | (空欄=同じサイト) | 別サイトのリストを使うときだけ |
| 会社休日リスト | Lists/CompanyHolidays | |
| 管理者の SharePoint グループ名 | 行動予定表管理者 | |
| 作業員の行き先リストのあるサイトの URL | (空欄) | 例 `https://<テナント>.sharepoint.com/sites/msteams_92936b` |
| 作業員の行き先リスト | (空欄=使わない) | `Lists/List`(リストの URL の `/Lists/` からうしろ) |
| 作業員の行き先を反映する部署 | 作業員 | この部署の人だけ、作業員の行き先リストの内容を出す。空欄なら全員 |

- 設定を変えたら「適用」を押す
- 休暇・休日出勤・会社休日のリストが読めないときは、予定表は表示したまま、上に黄色いお知らせが出る
- 予定表そのものが読めないときは、エラーの下に「くわしい内容(管理者向け)」が出る。状態コード 400 は列名のまちがい、404 はリスト名のまちがいのことが多い
