# SharePoint リストの準備と、WEBパーツの設定(開発者向け)

## 1. 行動予定リストを作る(社内ポータル。WorkerNameList と同じサイト)
- リストは最初に `ScheduleEntries` という名前で作り、あとから表示名を「行動予定」に変える
  - WEBパーツはリストを **URL(`Lists/ScheduleEntries`)で探す** ので、表示名を変えても動く
- 列は**最初に英語の名前(内部名)で作り**、あとから表示名を日本語に変える(内部名はあとから変えられないため)

| 内部名(最初にこの名前で作る) | 表示名(あとで変更) | 種類 | 必須 | 補足 |
|---|---|---|---|---|
| Title | 行き先・現場名 | 1行テキスト(既定の列) | ○ | 表示名を変えるだけ |
| Worker | 担当者 | 参照(WorkerNameList の「タイトル」) | ○ | |
| EntryType | 登録種別 | 選択肢:期間/単発 | ○ | |
| Category | 区分 | 選択肢:現場/在社/外出/出張/研修/休み/その他 | ○ | 選択肢はあとから追加・変更してよい(WEBパーツの作り直しは不要) |
| StartDate | 開始日 | 日付と時刻 →「日付のみ」 | ○ | |
| EndDate | 終了日 | 日付と時刻 →「日付のみ」 | ○ | |
| StartTime | 開始時刻 | 1行テキスト | | |
| EndTime | 終了・戻り時刻 | 1行テキスト | | |
| Note | メモ | 複数行テキスト | | 書式なし(プレーンテキスト) |

- **インデックス**(リストの設定 →「インデックス付きの列」):Worker・StartDate・EndDate
- **権限**
  - リストの設定 → 詳細設定:「読み取り:すべてのアイテム」「作成と編集:ユーザーが作成したアイテムのみ」
  - 一般社員:このリストに「投稿」
  - SharePoint グループ「行動予定表管理者」を作り、このリストに「編集」

## 2. 会社休日
- A. 既存のリスト(別サイト)をそのまま使う:WEBパーツの設定に「サイトの URL」と「リスト名」を入れる。全社員に読み取り権限が必要
- B. 社内ポータルに新しく作る:リスト `CompanyHolidays`(Title / HolidayDate(日付のみ)/ DayType(選択肢:休日/出勤日))。権限は全員「読み取り」
- どちらでも、列の内部名がちがうときは `src/services/spConfig.ts` の `holidays` を直す

## 3. 列の内部名を確かめる
次の URL をブラウザで開く(`<テナント>`・`<サイト>`・リスト名を差し替える)。結果を Claude Code に共有する。
```
https://<テナント>.sharepoint.com/sites/<サイト>/_api/web/lists/getbytitle('リスト名')/fields?$filter=Hidden eq false&$select=Title,InternalName,TypeAsString
```
対象:WorkerNameList、休暇情報共有リスト、休日出勤情報共有リスト、(A のとき)既存の休日リスト

内部名は `src/services/spConfig.ts` の `SP_FIELDS` 1か所で設定している(【要確認】の印があるのが仮の値)。

## 4. WEBパーツの設定(ページの編集 → WEBパーツの鉛筆マーク)
| 項目 | 初期値 | 説明 |
|---|---|---|
| 予定表に出さない部署 | 退職者 | 「、」か改行で区切って複数 |
| 「自分を一番上に表示」を最初からオン | オン | |
| 休暇と単発予定が重なったら休暇を優先 | オン | CLAUDE.md 6-2 の【要確認】 |
| 行動予定リスト | Lists/ScheduleEntries | リスト名、または `Lists/〜` の URL |
| 対象者リスト | WorkerNameList | |
| 休暇情報共有リスト | 休暇情報共有リスト | 【要確認】実際のリスト名に合わせる |
| 休日出勤情報共有リスト | 休日出勤情報共有リスト | 【要確認】実際のリスト名に合わせる |
| 会社休日リストのあるサイトの URL | (空欄=同じサイト) | 別サイトのリストを使うときだけ |
| 会社休日リスト | Lists/CompanyHolidays | |
| 管理者の SharePoint グループ名 | 行動予定表管理者 | |

- 設定を変えたら「適用」を押す
- 休暇・休日出勤・会社休日のリストが読めないときは、予定表は表示したまま、上に黄色いお知らせが出る
- 予定表そのものが読めないときは、エラーの下に「くわしい内容(管理者向け)」が出る。状態コード 400 は列名のまちがい、404 はリスト名のまちがいのことが多い
